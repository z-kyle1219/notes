# 变量与对象

## 变量是数据对象的标签

赋值操作建立的是名字与对象之间的绑定关系

在py中，对象是广义概念，dict/list/int都是内置类的实例，都是对象

## 命名规则

- 1.不能数字开头
- 2.不能使用内置关键字作为变量名称
- 3.严格区分大小写
- 4.最多由字母，下划线，数字组成

## 基本数据类型

- int 整数
- float 浮点数
- str 字符串
- bool 布尔 用来表示真假`True` `False`
- NoneType     None
- list tuple dict set

## f-string 字符串格式化

f-string字符串格式化 ：字符串前面加一个 f，花括号 `{}` 里可以直接写变量名

```python
print(f"我{age}岁了")
```

## 可变类型

可变类型：list,dict,set 可以在原内存地址上进行修改，所有指向它的变量都同步变化

```python
a = [1, 2, 3, 4, 5]
b = a
b = [1, 2, 3, 4, 5, 6]           # b指向了新对象
print(a)
```

## 不可变类型

不可变类型：int float str tuple 无法在原内存修改，会重新创建新对象并赋值

对于不可变类型，是换指向而非修改原数据

```python
x=10
x=100
```

## 动态类型

Python 是动态类型语言，不需要提前声明类型   `int x=10`会报错.可以用`type`查看变量类型

变量的类型在运行时根据赋的值自动确定，不需要提前声明；同一个变量甚至可以先后存不同类型的值
