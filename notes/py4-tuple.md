# 元组

## 元组（）：元素允许重复

有序序列，元组是不可变序列，无法增删，无法修改内部元素，支持索引，遍历与切片（与列表一样，也是[start:stop:step]），也可以混合类型

### 元组中保存的引用不能被替换

如果这个引用指向的是一个可变对象比如列表，仍然可以修改那个列表对象本身，引用可理解为一个对象在内存中的指向，新列表让元组的这个位置改去指向另一个对象，而增删让原来指向的那个列表对象自己发生变化

```python
mixed = (1, "hello", 3.14, True)   # 小括号中括号区分列表与元组
```

## 单元素元组

```python
single = (5,)   # 代表包含一个元素的元组
```

## 切片

列表与元组的切片：都是浅拷贝

步长决定方向；起始位置和终止位置必须符合这个方向，否则就是空列表。

起始和终止为空时,步长为负反转

## 元组解包

把元组里的值取出来，分别让新的变量指向这些值，但原来的元组没有被修改

```python
point = (3, 5)
x, y = point               # 一行代码同时把两个值分别赋给x和y
print(x, y)
```

## 函数返回多个值

使用函数返回多个值时会把多个返回值隐式打包为一个元组，再元组解包实现接收返回的多个值

如后端校验逻辑：成功标志+详细信息

```python
def validate_user(username, password):
    """校验用户输入，返回(是否成功, 错误信息)"""
    if len(username) < 3:
        return False, "用户名太短"
    if len(password) < 8:
        return False, "密码太短"
    return True, None

is_valid, error_msg = validate_user("ab", "123")
if not is_valid:
    print(f"校验失败：{error_msg}")
```

## 元组四大应用

1. 函数返回多值
2. 元组解包
3. 作为不可变的记录型数据
4. 作为字典的 key
