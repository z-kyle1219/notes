## 栈 Stack：应用程序撤销功能的原理

- 是一种**后进先出**的数据结构
- 主要的两个操作：压入 `push()` 和弹出 `pop()`
- `push()` 前要考虑栈是否满
- `pop()` 前要考虑栈是否空

### A. 顺序栈

由一个数组 `data` + 一个指针 `top` 表示（不是真正的指针类型，是整数下标）。

`top` 存的是栈顶元素在数组里的下标，栈顶是最后进来的，也就是最新入栈的那个元素。所以 `top == -1` 是空，`top == MAXSIZE-1` 是满。

**入栈 push 的原理：** 栈顶往上挪一格 → `top` 加 1，往新格子写数据。

```cpp
data[++top] = e;
```

前置 `++top`，先把 `top` 加 1，再用加完后的 `top` 值。栈顶上移一格，把 `e` 写进新的栈顶格。

所以 `push` 只需要按值传参即可。

**出栈 pop 的原理：** 把当前栈顶的值取出来，栈顶往下退一格 → `top` 减 1。栈的值不会消失，取出的核心是值赋给调用者（一个函数结束后依然存在的变量）。

```cpp
e = data[top--];
```

后置 `top--`，先用 `top` 现在的值，用完之后再减 1。

`pop` 通过在函数内真正修改传入的参数来实现把值从函数里带出去，所以**引用传参**。

#### 如果 top 存的是栈顶元素的下一个位置

两种约定放在一起对照：

| 约定 | 空 | 满 | 入栈 | 出栈 |
| --- | --- | --- | --- | --- |
| `top` 存**栈顶元素**的下标 | `top == -1` | `top == MAXSIZE-1` | 栈顶往上挪一格 → `top` 加 1，往新格子写数据<br>`data[++top] = e;` | 把当前栈顶的值取出来，`top` 减 1<br>`e = data[top--];` |
| `top` 存**栈顶元素的下一个位置** | `top == 0` | `top == MAXSIZE` | 先写数据，再 `top+1`<br>`data[top]=e;`<br>`top++;` | 先退一格，再取数据<br>`e=data[--top];` |

<aside class="callout">
<p class="t">补充 · 依据：由上面两种约定的定义推导</p>
<p>换约定以后元素个数也跟着变：第一种空栈时 <code>top = -1</code>，放进 3 个元素后 <code>top = 2</code>，个数是 <code>top + 1</code>；第二种空栈时 <code>top = 0</code>，放进 3 个元素后 <code>top = 3</code>，个数就是 <code>top</code>。考试换约定出题，先认这个。</p>
</aside>

### B. 链栈

链栈本质上就是单链表，带头节点（不存数据），栈顶放在链表头部（因为链表头部插入和删除都是 O(1)），链栈入栈、出栈都在头部进行。

`top` 指向头节点，`top->next` 指向栈顶。

**入栈就是把新节点插头节点之后：**

```cpp
s->next = top->next;
top->next = s;
```

先让新节点指向原来的第一个节点（原栈顶），再让头节点指向新节点（新栈顶）。

**出栈：**

```cpp
p = top->next;
top->next = p->next;
delete p;
```

让 `p` 指向栈顶，让头节点的 `next` 指向 `p`（栈顶）的下一个节点，释放原栈顶的内存。

### 栈经典应用

#### 1. 括号匹配

- **原理：** 因为括号具有后出现的左括号需要先匹配的特点
- **匹配算法：** 循环：遇到左括号就入栈，遇到右括号，若栈为空，则报错，若与栈顶元素匹配就弹出，否则就报错，循环结束，栈为空
- **做法：** 初始化栈，栈空，栈满，入栈，出栈，取栈顶元素

#### 2. 后缀表达式

- **原理：** 后出现的数先匹配运算符
- 先弹出的是右操作数，后弹出的是左操作数

#### 3. 中缀表达式转后缀表达式

**a.** 遇到字母或数字：直接放进后缀表达式，不入栈。

**b.** 遇到运算符：和栈顶运算符比较优先级。

- 栈顶优先级更高或相同：弹出栈顶，输出栈顶，输入新运算符
- 栈顶优先级更低：当前运算符入栈

**c.** 遇到括号

- `(`：直接入栈，作为一个边界
- `)`：不断弹出并输出运算符，直到遇到 `(`；`(` 只弹出，不输出

**d.** 遍历结束，将栈中剩余的所有运算符依次弹出并输出。

### 栈与递归

递归的两个必要条件：

- **递归出口：** 满足条件后停止递归
- **递归关系：** 将问题转化为规模更小的子问题

## 队列 Queue：先进先出

- 先进先出，**一端插入，另一端删除**
- 栈优先服务于最新的元素，队列优先服务于最早的元素
- 主要的两个操作：入队 `enqueue()`，出队 `dequeue()`
- 入队：队尾添加元素，队列是否已满
- 出队：队头移除元素，队列是否为空

### A. 顺序队列

由一个数组 + 队头 `front`、队尾 `rear` 两个下标表示。

其中 `front` 指向队头第一个有效元素；`rear` 不是指向当前队尾元素，而是指向下一个空位置。

**入队 enqueue：** 先判断队列是否已满，`rear == MAX`

```cpp
q[rear] = x;   rear++;
```

**出队 dequeue：** 判断队列是否为空，`front == rear`

没有真的把数组中的队头删除，只是让 `front` 向后移动了一格。队列当前有效的数据是 `front` 到 `rear - 1` 之间的元素。

### 普通队列的缺点：空间浪费

假设数组容量是 5，依次入队 10、20、30、40、50，再出队两个元素。

虽然前两个位置已经空出来，但 `rear` 已经等于 5。此时再执行 `enqueue(60)`，代码仍会提示队列已满。**假溢出。**

### 循环队列：让数组首尾相连，解决假溢出问题

当队尾走到数组末尾时，如果前面有空位，就绕回数组开头继续存数据。

**绕回去的办法：取余运算**

```text
入队：rear = (rear + 1) % MAX;   用 % MAX 控制下标，让它始终在合法范围内循环移动
出队：front = (front + 1) % MAX
```

同时保证了队列的先进先出规则。

但因为循环队列**队空和队满都是 `front == rear`**，无法判断：

- 队空时 `front == rear == 0`
- 队满时 `rear` 指向最后一个元素的下一位，又到了 `front`

两种办法：

1. 同时引入 `count` 来统计队列中元素个数
2. 如果不使用 `count` 时：牺牲一个存储单元，增加判满

在具有 n 个单元的循环队列中，队满时共有 **n-1** 个元素。

```cpp
bool isFull() {
    return (rear + 1) % MAX == front;
}
```

### B. 链式队列

带头节点的链式队列，空队列时两个指针都指向头节点。`front` 指向头节点，`rear` 指向最后一个数据节点。

**入队：`rear` 动**

```cpp
rear->next = s;
rear = s;
```

原来队尾节点指向新节点，`rear` 移动到新节点。

**出队：`front` 动**

```cpp
p = front->next;
front->next = p->next;
delete p;
```

注意，如果只有一个元素，出队后，`rear` 还指向刚刚被删除的元素，变成了**野指针**，要做异常兜底：

```cpp
if (front->next == NULL)
{
    rear = front;
}
```
