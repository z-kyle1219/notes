栈Stack：应用程序撤销功能的原理
是一种后进先出的数据结构
主要的两个操作：压入push()和弹出pop()
push（）前要考虑栈是否满
pop（）前要考虑栈是否空

A.顺序栈
由一个数组data  +一个指针top表示（不是真正的指针类型，是整数下标）
top 存的是栈顶元素在数组里的下标，栈顶是最后进来的，也就是最新入栈的那个元素
所以top == -1 是空，top == MAXSIZE-1 是满
入栈push的原理：栈顶往上挪一格 → top 加 1，往新格子写数据

data[++top] = e; 
前置 ++top，先把 top 加 1，再用加完后的top值
栈顶上移一格，把 e 写进新的栈顶格

所以push只需要按值传参即可

出栈pop的原理：把当前栈顶的值取出来，栈顶往下退一格 → top 减 1
栈的值不会消失，取出的核心是值赋给调用者（一个函数结束后依然存在的变量）
e = data[top--];
 后置 top--，先用 top 现在的值，用完之后再减 1
pop通过在函数内真正修改传入的参数来实现把值从函数里带出去，所以引用传参

如果top存的是栈顶元素的下一个位置
top==0是空，top==MAXSIZE是满
入栈原理是先写数据，再top+1
data[top]=e;
top++;
出栈原理是先退一格，再取数据
e=data[--top];


B.链栈
链栈本质上就是单链表，
带头节点（不存数据），栈顶放在链表头部(因为因为链表头部插入和删除都是 O(1))，链栈入栈、出栈都在头部进行
top指向头节点， top->next指向栈顶
入栈就是把新节点插头节点之后
s->next = top->next;
top->next = s;
先让新节点指向原来的第一个节点（原栈顶），再让头节点指向新节点（新栈顶）
出栈：
p = top->next;
top->next = p->next;
delete p;
让p指向栈顶，让头节点的next指向p（栈顶）的下一个节点，释放原栈顶的内存

栈经典应用：
1.括号匹配
原理：因为括号具有后出现的左括号需要先匹配的特点
匹配算法：循环：遇到左括号就入栈，遇到右括号，若栈为空，则报错，若与栈顶元素匹配就弹出，否则就报错，循环结束，栈为空
做法：初始化栈，栈空，栈满，入栈，出栈，取栈顶元素

2.后缀表达式
原理：后出现的数先匹配运算符
先弹出的是右操作数，后弹出的是左操作数

3.中缀表达式转后缀表达式
a.遇到字母或数字：直接放进后缀表达式，不入栈。
b.遇到运算符：和栈顶运算符比较优先级。
栈顶优先级更高或相同：弹出栈顶，输出栈顶，输入新运算符
栈顶优先级更低：当前运算符入栈
c.遇到括号
(：直接入栈，作为一个边界
)：不断弹出并输出运算符，直到遇到 (；( 只弹出，不输出
d.遍历结束，将栈中剩余的所有运算符依次弹出并输出
4.进制转换
如十进制转八进制
原理：不断除以 8，记录余数，最后逆序输出余数

队列Queue：先进先出，一端插入，另一端删除
栈优先服务于最新的元素，队列优先服务于最早的元素
主要的两个操作：入队enqueue()，出队dequeue()
入队：队尾添加元素，队列是否已满
出队：队头移除元素，队列是否为空

A.顺序队列
由一个数组+队头(front)，队尾(rear)两个下标表示，
其中rear不是指向当前队尾元素，而是指向下一个空位置
入队enqueue： q[rear] = x;   rear++;
先判断队列是否已满，rear==MAX
 q[rear] = x;   rear++;
出队dequeue：
判断队列是否为空，front==rear
没有真的把数组中的队头删除，只是让 front 向后移动了一格。 队列当前有效的数据是 front 到 rear - 1 之间的元素。

普通队列的缺点：空间浪费
假设数组容量是 5，依次入队 10、20、30、40、50，再出队两个元素。
虽然前两个位置已经空出来，但 rear 已经等于 5。此时再执行 enqueue(60)，代码仍会提示队列已满。假溢出

循环队列：让数组首尾相连，解决假溢出问题
当队尾走到数组末尾时，如果前面有空位，就绕回数组开头继续存数据
绕回去的办法：取余运算
入队：rear = (rear + 1) % MAX;   用 % MAX 控制下标，让它始终在合法范围内循环移动
出队：front = (front + 1) % MAX
同时保证了队列的先进先出规则

但因为循环队列队空和队满都是front == rear，无法判断，
队空时front==rear==0,队满时rear指向最后一个元素的下一位又到了front
两种办法：
1.同时引入count来统计队列中元素个数
2.如果不使用count时：牺牲一个存储单元，增加判满
在具有n个单元的循环队列中，队满时共有      n-1    个元素，
具体操作：
bool isFull() {
    return (rear + 1) % MAX == front;
}

B.链式队列
带头节点的链式队列，空队列时两个指针都指向头节点
front指向头节点，rear指向最后一个数据节点
入队：rear动
rear->next = s;
rear = s;
原来队尾节点指向新节点
rear 移动到新节点
出队：front动
p=front->next;
front->next=p->next;
delete p;
注意，如果只有一个元素，出队后，rear 还指向刚刚被删除的 元素，变成了野指针，要做异常兜底
if (front->next == NULL)
{
    rear = front;
}
只允许使用两个栈，实现一个先进先出的队列
